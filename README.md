# ABYSS DIVER 🐠

3인칭 시점으로 심해를 유영하는 **3D 수중 탐험 슈팅**.
빌드 과정 없이 `index.html` 하나로 실행되는 정적 웹앱입니다. (Three.js ES Module, CDN)

## 어떤 게임인가요

잠수정 뒤쪽 위에서 바라보는 3인칭 카메라로 심해를 전진합니다.
주변으로 대왕고래와 만타가오리, 바다거북, 물고기 떼가 유유히 헤엄쳐 지나가고,
산호초와 해초, 수면에서 내려오는 빛줄기, 상승하는 기포가 시야를 채웁니다.

그 사이로 기계 상어와 발광 해파리, 기뢰가 다가옵니다. 조준선을 맞추면 어뢰가
자동으로 발사되어(호밍) 적을 격파합니다. 3웨이브마다 거대 심해 보스가 등장합니다.

- **분위기**: `FogExp2` 수중 안개, 수면 빛줄기(갓 레이), 발광 플랑크톤, 잠수정 전조등
- **관상용 대형 생물**: 대왕고래 · 만타가오리 · 바다거북 · 물고기 떼 (공격하지 않음)
- **깊이감**: 산호초 지대 → 해저 협곡 → 심해 발광 지대로 이어지는 3개 구역
- **아이와 함께**: 체력 5칸, 자동 연사, 한 손가락 드래그만으로 조작

## 조작

| 환경 | 조작 |
| --- | --- |
| 📱 모바일 | 화면을 **한 손가락으로 드래그** (자동 연사) |
| 🖥 PC | **마우스 이동** 또는 **방향키 / WASD** |
| 〰 음파 폭탄 | 우하단 〰 버튼 또는 **Space** |
| ⏸ 일시정지 | 우상단 ❚❚ 또는 **P / Esc** |
| 🔊 음소거 | 우상단 스피커 또는 **M** |

발사는 자동입니다. 레티클이 적을 향하면 붉게 잠기고, 어뢰가 유도됩니다.

## 게임 요소

### 적
| 적 | 특징 |
| --- | --- |
| 기계 상어 | 플레이어를 향해 유도 돌진. 꼬리를 흔들며 접근합니다. |
| 발광 해파리 | 느리게 표류하며 부풀었다 줄어듭니다. 접촉에 주의. |
| 기뢰 | 제자리에서 깜빡이며 떠다닙니다. 맞으면 크게 폭발합니다. |
| 심해 포식자 (보스) | 3웨이브마다 등장하는 거대 아귀. 발광 루어와 함께 구체를 발사합니다. |

### 아이템
| 아이템 | 효과 |
| --- | --- |
| 🎯 멀티 어뢰 (분홍) | 어뢰 3발 동시 발사 (13초) |
| ⚡ 연사 강화 (하늘) | 발사 속도 2배 (13초) |
| 🛡 수중 실드 (보라) | 피해 2회 흡수 |
| 〰 음파 폭탄 (호박) | 화면 전체를 정리하는 음파 폭발 +1 |

### 진행
- 웨이브마다 목표 격파 수가 늘어나고, 3·6·9… 웨이브에서 보스가 등장합니다.
- 수심(Depth m)이 실시간으로 기록되고, 최고 점수는 `localStorage`에 저장됩니다.

## 기술

- **Three.js r169** — importmap + jsdelivr ES Module, 빌드 없음
- 모델은 전부 **절차적 메시**(구·원뿔·원통 병합)로 제작, 외부 에셋 0개
- 성능: `pixelRatio` 상한 2 + 자동 화질 하향, 지오메트리 병합, 적 머티리얼 공유,
  파티클은 단일 `Points` 드로우콜, 안개로 원거리 컬링
- 아이폰 사파리 대응: `touch-action: none`, `user-scalable=no`, `overscroll-behavior: none`,
  세이프 에어리어 패딩, Web Audio 첫 터치 언락
- 사운드는 Web Audio API 실시간 합성 (소나 핑, 어뢰, 폭발, 기포, 음파)

## 파일 구조

```
index.html      화면 · HUD · importmap
style.css       수중 UI 스타일
js/main.js      게임 루프 · 플레이어 · 적 · 웨이브 · HUD
js/world.js     해저 지형 · 산호초 · 빛줄기 · 관상용 생물
js/models.js    절차적 3D 모델 빌더
js/fx.js        파티클 · 폭발 · 음파 링
js/audio.js     수중 효과음 엔진
```

## 로컬 실행

```bash
python3 -m http.server 8000
# http://localhost:8000
```
