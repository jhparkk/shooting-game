# ABYSS DIVER 🐠

3인칭 시점으로 심해를 **자유롭게 유영하는 3D 수중 탐험 슈팅**.
빌드 과정 없이 `index.html` 하나로 실행되는 정적 웹앱입니다. (Three.js ES Module, CDN)

## 어떤 게임인가요

잠수정 뒤쪽 위에서 따라오는 3인칭 카메라로, 넓은 바다를 **앞·뒤·좌·우·상·하로
직접 조종해 자유롭게 누빕니다.** 대왕고래와 만타가오리, 바다거북, 물고기 떼가 함께
헤엄치고, 산호초와 해초, 수면에서 쏟아지는 빛줄기, 상승하는 기포가 시야를 채웁니다.

**얕은 산호 언덕(수심 15~30m)에서 깊은 해저 협곡·해구(수심 60~110m)까지** 이어지는
입체 해저 지형을 따라 내려가며 탐험합니다. 내려갈수록 물빛이 맑은 에메랄드에서
깊은 코발트블루로 바뀌고, 그 깊이에 사는 생물이 나타납니다. 조준선을 맞추면 어뢰가
자동으로 발사되어(호밍) 적을 격파합니다. 3웨이브마다 거대 대왕오징어 크라켄이 등장합니다.

- **분위기**: 맑고 밝은 에메랄드빛 바다, 수면 빛줄기(갓 레이), 발광 플랑크톤, 잠수정 전조등
- **관상용 생물**: 대왕고래 · 만타가오리 · 바다거북 · 물고기 떼 (공격하지 않음)
- **적**: 백상아리 · 귀상어 · 독가시 복어 · 쏠배감펭 · 발광 해파리 · 심해 아귀 (기계 없음)
- **공간감**: 바위 아치(수중 터널), 굽이치는 해저 협곡과 깊은 해구, 수심에 따른 물빛 변화
- **아이와 함께**: 체력 5칸, 자동 연사, 한 손가락 드래그만으로 조작

## 조작

| 환경 | 조작 |
| --- | --- |
| 📱 조이스틱 (왼쪽 아래) | 드래그로 **전진·후진 · 좌우 회전** |
| 📱 고도 (오른쪽 ▲▼) | **상승 · 하강** |

| 〰 음파 폭탄 | 〰 버튼 또는 **B** |
| ⏸ 일시정지 | 우상단 ❚❚ 또는 **P / Esc** |
| 🔊 음소거 | 우상단 스피커 또는 **M** |

레티클이 적을 향하면 붉게 잠기고, 어뢰가 부드럽게 유도됩니다.

## 게임 요소

### 적
| 적 | 특징 |
| --- | --- |
| 백상아리 | 플레이어를 향해 유도 돌진. 꼬리를 흔들며 빠르게 접근합니다. |
| 귀상어 | 망치 모양 머리의 상어. 느리지만 단단하고 크게 흔들리며 돌진합니다. |
| 독가시 복어 | 천천히 떠다니며 몸을 부풀립니다. 닿으면 가시가 터집니다. |
| 쏠배감펭 | 긴 독가시 지느러미를 펼친 채 느리게 접근합니다. |
| 발광 해파리 | 느리게 표류하며 부풀었다 줄어듭니다. 접촉에 주의. |
| 심해 아귀 | 깊은 해구에 사는 포식자. 유인 돌기를 밝히며 이빨을 드러냅니다. |
| 대왕오징어 크라켄 (보스) | 3웨이브마다 등장. 8가닥 다리와 긴 촉수를 휘젓고 구체를 발사합니다. |

### 아이템
| 아이템 | 효과 |
| --- | --- |
| 🎯 멀티 어뢰 (분홍) | 어뢰 3발 동시 발사 (13초) |
| ⚡ 연사 강화 (하늘) | 발사 속도 2배 (13초) |
| 🛡 수중 실드 (보라) | 피해 2회 흡수 |
| 〰 음파 폭탄 (호박) | 화면 전체를 정리하는 음파 폭발 +1 |

### 진행
- 웨이브마다 목표 격파 수가 늘어나고, 3·6·9… 웨이브에서 보스가 등장합니다.
- 수심(Depth m)이 실시간으로 기록되고, 최고 점수는 `localStorage`에 저장됩니다.

## 기술

- **Three.js r169** — importmap + jsdelivr ES Module, 빌드 없음
- 모델은 전부 **절차적 메시**(구·원뿔·원통 병합)로 제작, 외부 에셋 0개
- 성능: `pixelRatio` 상한 2 + 자동 화질 하향, 지오메트리 병합, 적 머티리얼 공유,
  파티클은 단일 `Points` 드로우콜, 안개로 원거리 컬링
- 아이폰 사파리 대응: `touch-action: none`, `user-scalable=no`, `overscroll-behavior: none`,
  `js/zoom-guard.js`(핀치 줌·더블탭 줌·트랙패드 확대 차단), 세이프 에어리어 패딩, Web Audio 첫 터치 언락
- 사운드는 Web Audio API 실시간 합성 (소나 핑, 어뢰, 폭발, 기포, 음파)

## 파일 구조

```
index.html      화면 · HUD · importmap
style.css       수중 UI 스타일
js/zoom-guard.js 사파리 확대(핀치·더블탭 줌) 차단 가드
js/main.js      게임 루프 · 플레이어 · 적 · 웨이브 · HUD
js/world.js     해저 지형 · 산호초 · 빛줄기 · 관상용 생물
js/models.js    절차적 3D 모델 빌더
js/fx.js        파티클 · 폭발 · 음파 링
js/audio.js     수중 효과음 엔진
```

## 로컬 실행

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://`로 열면 ES Module 보안 정책 때문에 동작하지 않습니다. 간단한 정적 서버로 열어 주세요.
